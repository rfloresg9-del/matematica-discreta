Crear grafo no dirigido

Selecciona los vértices A, B, C… y escribe las aristas como pares separados por comas, una por línea o separadas por punto y coma. El programa buscará una trayectoria que visite todos los vértices una sola vez.

Ejemplo que sí tiene trayectoria: A,B; B,C; C,D; D,E. Ejemplo que no tiene: A,B; B,C; C,D; C,E.
